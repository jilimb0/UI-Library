# Тестирование

Описание процесса тестирования в UI библиотеке.

## Инструменты
- Jest
- React Testing Library
- Cypress (для e2e)

## Типы тестов
- Unit-тесты для компонентов
- Интеграционные тесты для взаимодействия компонентов
- E2E тесты для пользовательских сценариев

## Запуск тестов
```bash
npm test
# или
yarn test
```

## Покрытие тестами
- Используйте `jest --coverage` для отчета о покрытии
- Поддерживайте покрытие не менее 80%
