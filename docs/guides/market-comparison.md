# Market Comparison

This guide summarizes the product positioning used by the launch checklist.

## Positioning

- UI Construction Library is an owned, workspace-native component system with a builder, docs, demo-showcase, and export pipeline.
- The platform emphasizes deterministic exports, accessibility, and maintainable monorepo boundaries.

## Competitive differentiators

- Owned primitives and interactions instead of direct third-party runtime coupling.
- Explicit export targets and source registry metadata.
- Launch and release documentation that fits the repo’s validation workflow.

## When to update

- Update this guide when the public feature set materially changes.
- Revisit before major releases or certification milestones.
