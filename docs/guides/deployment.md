# Деплой

Руководство по деплою UI библиотеки и приложений.

## Подготовка
- Убедитесь, что все тесты проходят
- Соберите продакшен сборку (`npm run build`)

## Деплой на Vercel
- Настройте проект на Vercel с монорепозиторием
- Воспользуйтесь встроенной поддержкой TurboRepo
- Переменные окружения через Vercel

## Деплой на другие хостинги
- Соберите билд и загрузите в хранилище статики
- Настройте CI/CD для автоматизации
