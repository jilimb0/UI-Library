# Решение проблем

Справочник по решению частых проблем в разработке UI библиотеки.

## Проблемы с типами
- Проверяйте версии TypeScript и typings
- Используйте `tsc --noEmit` для проверки

## Проблемы с линтингом
- Запускайте `eslint . --fix` для автоматического исправления
- Убедитесь в правильной конфигурации ESLint

## Проблемы с зависимостями
- Перезапустите `node_modules` (rm -rf node_modules && npm install)
- Следите за версиями пакетов

## Проблемы с билдом
- Проверяйте логи сборки
- Используйте `next build` для проверки ошибок
