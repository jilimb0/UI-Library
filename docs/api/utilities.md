# API утилит

Описание вспомогательных утилит и функций библиотеки.

## formatDate
- Описание: форматирует дату в строку.
- Аргументы:
  - `date`: Date - объект даты
  - `format`: string - строка формата (например, 'YYYY-MM-DD')
- Возвращает: string - отформатированная дата

## debounce
- Описание: функция для debounce вызова функции.
- Аргументы:
  - `func`: Function - вызываемая функция
  - `wait`: number - время ожидания в мс
- Возвращает: Function - задебаунсенная функция

## classNames
- Описание: объединяет классы в строку для Tailwind CSS.
- Аргументы:
  - `...classes`: string[] - список классов
- Возвращает: string - объединённая строка классов
