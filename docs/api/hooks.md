# API hooks

Документация по основным хукам в UI библиотеке.

## useToggle
- Описание: хук для переключения булевого состояния.
- Возвращает: массив [boolean, () => void]

## useDebounce
- Описание: хук для debounce значения.
- Аргументы:
  - `value`: T - входное значение
  - `delay`: number - задержка в мс
- Возвращает: T - дебаунснутый результат

## useFetch
- Описание: хук для получения данных с API.
- Аргументы:
  - `url`: string - адрес API
- Возвращает: объект с { data, error, loading }
