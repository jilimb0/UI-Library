# Feedback SLA

This note defines response targets for launch feedback. It complements the canonical release docs in [`README.md`](./README.md) and [`RELEASE_RUNBOOK.md`](./RELEASE_RUNBOOK.md).

## Response targets

- Launch-blocking issues: acknowledge within 1 business day.
- High-priority product or release issues: triage within 2 business days.
- General feedback: review in the next planning cycle.

## Handling

- Convert validated issues into tracked backlog items.
- Keep the release owner informed until the issue is closed or intentionally deferred.
