# Release Docs Index

Use these four docs as the canonical release set:

1. [`RELEASE_RUNBOOK.md`](./RELEASE_RUNBOOK.md) — how to cut, publish, verify, and roll back releases.
2. [`PR_CHECKLIST.md`](./PR_CHECKLIST.md) — release-candidate checklist for code, build, demo, and approvals.
3. [`RELEASE_NOTES_TEMPLATE.md`](./RELEASE_NOTES_TEMPLATE.md) — template for public release notes.
4. [`LTS_VERSIONING_POLICY.md`](./LTS_VERSIONING_POLICY.md) — versioning, support, deprecation, and rollback policy.

The remaining files in this folder are supporting launch artifacts and program notes. Keep them short and reference the canonical set above instead of repeating policy.
