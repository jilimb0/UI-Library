# v1.0.0 Release Checklist

## Prerequisites
- [ ] All 14 packages have `version` bumped via Changesets
- [ ] All packages publish to npm successfully (`pnpm publish -r`)
- [ ] CHROMATIC_PROJECT_TOKEN is set in GitHub Secrets
- [ ] All CI workflows pass on main

## Quality Gates
- [ ] `pnpm validate` passes (lint + typecheck + test + build)
- [ ] Cross-browser E2E tests pass (chromium + firefox + webkit)
- [ ] Chromatic visual regression tests pass (no unexpected changes)
- [ ] Coverage thresholds ≥80% for all packages with tests

## Documentation
- [ ] CHANGELOG updated for all packages
- [ ] ROADMAP updated (mark v1.0.0 as released)
- [ ] Migration guide from v0.x → v1.0.0 (if breaking changes)

## Release Steps
1. `pnpm changeset version` — bump versions
2. `pnpm validate` — final check
3. `pnpm release` — publish to npm
4. `git tag v1.0.0 && git push origin v1.0.0`
5. Verify all packages on npm
