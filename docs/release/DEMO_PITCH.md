# Demo Pitch Script (5-7 minutes)

## 1. Opening (30 sec)

- "This is our production-ready React UI library monorepo."
- "The demo shows real component usage, not isolated snippets."

## 2. Core UI (2 min)

- Show atoms: Button, Input, Select, Checkbox, Radio, Badge.
- Show molecules: Dropdown, DatePicker, Alert, Field.
- Show organisms: DataTable, Modal, Tabs, Form.

## 3. Developer Experience (1 min)

- Mention TypeScript-first APIs.
- Mention workspace packages and shared tokens/icons.
- Mention form integration (`react-hook-form`).

## 4. UX/A11y/Performance (1 min)

- Keyboard navigation in interactive components.
- Focus management in Modal.
- Built-in CI checks and performance budgets.

## 5. Delivery Pipeline (1 min)

- CI workflow for lint/test/build/typecheck.
- Demo auto-deploy to GitHub Pages.
- Release pipeline with Changesets.

## 6. Close (30 sec)

- "We can scale this into product-specific themes and domain components."
- Share links to demo and repository.
