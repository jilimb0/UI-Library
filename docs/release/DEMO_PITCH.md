# Demo Pitch Script (5-7 minutes)

This is a short presentation script for the demo showcase. Release policy lives in [`README.md`](./README.md), [`RELEASE_RUNBOOK.md`](./RELEASE_RUNBOOK.md), and [`RELEASE_NOTES_TEMPLATE.md`](./RELEASE_NOTES_TEMPLATE.md).

## 1. Opening (30 sec)

- "This is our production-ready React UI library monorepo."
- "The demo shows real component usage, not isolated snippets."
- "The flagship flows show how prompt, builder, export, and runnable demo fit together."

## 2. Flagship flows (2 min)

- SaaS landing page: prompt-driven acquisition surface with conversion proof.
- Dashboard shell: dense operational UI with safe edit and table-heavy workflows.
- Settings app: validation, permissions, and form-driven state.
- Docs page: route structure, sticky navigation, and public API storytelling.
- Pricing site: publish-ready layout with comparison and trust signals.

## 3. Core UI (1.5 min)

- Show atoms: Button, Input, Select, Checkbox, Radio, Badge.
- Show molecules: Dropdown, DatePicker, Alert, Field.
- Show organisms: DataTable, Modal, Tabs, Form.

## 4. Developer Experience (1 min)

- Mention TypeScript-first APIs.
- Mention workspace packages and shared tokens/icons.
- Mention form integration (`react-hook-form`).

## 5. UX/A11y/Performance (1 min)

- Keyboard navigation in interactive components.
- Focus management in Modal.
- Built-in CI checks and performance budgets.

## 6. Delivery Pipeline (1 min)

- CI workflow for lint/test/build/typecheck.
- Demo auto-deploy to GitHub Pages.
- Release pipeline with Changesets.

## 7. Close (30 sec)

- "We can scale this into product-specific themes, domain components, and repeatable flagship proof flows."
- Share links to demo and repository.
