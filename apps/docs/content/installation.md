
# Установка

Для начала установки выполните:

```
npm install @ui-construction-library/core @ui-construction-library/utils @ui-construction-library/tokens
```

Импортируйте компоненты и стили в ваш проект:

```tsx
import { Button } from '@ui-construction-library/core';
import '@ui-construction-library/core/styles';
```
