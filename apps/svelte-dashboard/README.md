# Svelte dashboard demo

Framework-agnostic usage of UCL Universal Core packages in Svelte:
- `@ui-construction-library/tokens` via `generateCSSVariables()` injection
- `@ui-construction-library/styles` via `styles.css`
- `@ui-construction-library/behaviors` via headless attribute factories

## Run

```bash
pnpm --filter @ui-app/svelte-dashboard dev
```
