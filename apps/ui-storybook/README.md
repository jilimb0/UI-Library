
# Storybook for UI Library

This Storybook setup provides interactive documentation and testing for the UI components in the library.

## Running Storybook

```bash
pnpm run storybook
```

## Building Static Storybook

```bash
pnpm run build-storybook
```

## Included Addons

- Essentials (Actions, Controls, Docs, Viewport, Backgrounds)
- Accessibility (a11y) testing
- Design Tokens
- Docs for Markdown and MDX files
