# @ui-construction-library/export-core

INTERNAL-ONLY: This package is not part of the public API surface.

Core export logic for @ui-construction-library — export project analysis and rendering.

## Exports

- `analyzeExportProject` — Analyze export project input
- `appendDoctorArtifacts` — Append doctor artifacts to rendered output
- `createExportRequestFromBuilderProject` — Create export request from builder project
- `enrichExportProject` — Enrich export project with additional data
- `normalizeExportProject` — Normalize export project input
- `renderExportProject` — Render export project to files
