# Support

## Where to get help

### GitHub Discussions

Use [GitHub Discussions](https://github.com/jilimb0/UI-Library/discussions) for:

- **Q&A** — "How do I use X component?", "What's the best pattern for Y?"
- **Ideas** — Feature requests and design proposals
- **Show and tell** — What you've built with the library
- **Community** — General conversation

### GitHub Issues

Use [GitHub Issues](https://github.com/jilimb0/UI-Library/issues) for:

- **Bug reports** — Something is broken or behaves unexpectedly
- **Feature requests** — Specific, actionable feature proposals

Before opening an issue, search existing issues and discussions to avoid duplicates.

### Security vulnerabilities

For security issues, **do not** open a public issue. See [SECURITY.md](.github/SECURITY.md) for our responsible disclosure process.

### Documentation

- [Getting started](./docs/guides/getting-started.md) — quick start guide
- [Integration kits](./docs/guides/integration-kits.md) — step-by-step setup for Vite, Next.js, and more
- [Storybook](https://main--6692d4e8c3a6b656d6e58e60.chromatic.com) — interactive component explorer
- [API reference](./docs/api/components.md) — component and utility documentation

## Expectations

- **Bug reports**: We aim to triage within 5 business days. Critical bugs get priority.
- **Feature requests**: We review and tag within 10 business days. Acceptance depends on roadmap alignment.
- **Q&A questions**: Community-driven via Discussions. Maintainers answer when they can.

## Enterprise support

For priority support, custom integrations, or training, contact the maintainers via GitHub Discussions or email.
